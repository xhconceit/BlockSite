# Proposal: AI 功能集成

## 动机

BlockSite 当前所有拦截规则、名言、调度均为静态/手动配置。用户需要：

1. 手动选择分类才能添加规则
2. 手动维护域名黑名单，新网站层出不穷
3. 使用固定的预设名言，缺乏个性化
4. 无法从统计中获得有用的洞察

AI 可以显著降低使用门槛：自动分类、自然语言建规则、智能识别未列出的同类型网站、个性化名言、统计解读。

## 目标

1. **AI 自动分类** — 添加网站时自动建议所属分类
2. **自然语言创建规则** — 输入「拦截所有社交媒体」AI 解析出具体域名规则
3. **智能动态拦截** — 访问网站时 AI 实时判断是否匹配拦截意图（分析 URL + 标题 + 页面正文）
4. **AI 生成名言** — 拦截页面显示 AI 根据拦截场景生成的个性化名言
5. **AI 统计洞察** — 分析拦截数据并给出改进建议
6. **多提供商支持** — Anthropic、OpenAI、DeepSeek、Ollama、OpenRouter
7. **调用记录** — AI 标签页查看所有调用历史

## 范围

| 模块                | 说明                                     |
| ------------------- | ---------------------------------------- |
| `@blocksite/ai` 包  | AI 客户端抽象层、提示词模板、各功能函数  |
| 存储层 `apiKeys` 表 | API Key 独立存储（与 auth 密码表同模式） |
| 后台消息处理        | 10 个 AI 消息处理器                      |
| Options AI 标签页   | API Key 管理 + 功能开关 + 调用记录       |
| Popup               | AI 自动分类建议                          |
| Options Rules 面板  | NL 智能规则输入 + 智能规则列表           |
| Dashboard           | AI Insights 分析面板                     |
| Blocked 页面        | AI 生成名言                              |
| i18n                | 中英文完整覆盖                           |

## 非目标

- 不内置 AI 模型，全部走外部 API
- 不修改现有用户数据的导入/导出格式（AI 设置为单独存储）
- 不在拦截页面进行实时 AI 内容分析（仅在智能拦截规则触发时调用 AI 分类）
