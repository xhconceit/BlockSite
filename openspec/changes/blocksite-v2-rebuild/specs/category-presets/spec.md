## 新增需求

### Requirement: 内置分类预设

系统应提供六个内置分类：社交、视频、游戏、新闻、成人和自定义。每个分类应有预定义的预设网站列表，用户可一键添加。

#### Scenario: 查看分类预设

- **WHEN** 用户打开"社交"分类的预设面板
- **THEN** 系统显示预设网站列表（如 facebook.com、twitter.com、instagram.com）

#### Scenario: 从预设一键添加

- **WHEN** 用户在社交分类中点击预设网站 "instagram.com" 的"添加"
- **THEN** 创建一条类型为域名、值为 "instagram.com"、分类为"社交"的新规则

### Requirement: 用户可编辑预设

系统应允许用户向任意分类添加自定义预设网站，以及删除已有预设网站。

#### Scenario: 添加预设网站

- **WHEN** 用户向社交分类预设中添加 "reddit.com"
- **THEN** "reddit.com" 出现在社交预设列表中，并在会话间持久化

#### Scenario: 删除预设网站

- **WHEN** 用户从社交分类预设中删除 "twitter.com"
- **THEN** "twitter.com" 从社交预设列表中移除

#### Scenario: 重置预设为默认值

- **WHEN** 用户将某分类的预设重置为默认值
- **THEN** 所有用户添加的预设被移除，内置预设恢复

### Requirement: 分类元数据

每个分类应有：唯一键名、显示标签、来自设计系统调色板的主题色。

#### Scenario: 分类主题色

- **WHEN** 属于"游戏"分类的规则拦截网站
- **THEN** 拦截页面以绿色主题色显示

#### Scenario: 自定义分类

- **WHEN** 用户以"自定义"分类创建规则
- **THEN** 该规则在拦截页面上使用靛蓝主题色

### Requirement: 分类相关语录

每个分类应有与该分类主题相关的默认励志语录集合。语录应针对具体的干扰类型编写。

#### Scenario: 社交分类语录

- **WHEN** 用户查看社交分类语录
- **THEN** 语录针对社交媒体，如"真正的朋友不在屏幕里"

#### Scenario: 游戏分类语录

- **WHEN** 游戏分类规则拦截网站
- **THEN** 显示的语录针对游戏，如"通关的人生不在游戏里"

#### Scenario: 视频分类语录

- **WHEN** 视频分类规则拦截网站
- **THEN** 显示的语录针对视频消费，如"算法的尽头不是充实"

#### Scenario: 新闻分类语录

- **WHEN** 新闻分类规则拦截网站
- **THEN** 显示的语录针对信息过载，如"99% 的新闻和你无关"

### Requirement: 用户可编辑语录

用户应能为每个分类增删改语录。每条语录应有文本字段和可选的作者字段。

#### Scenario: 添加自定义语录

- **WHEN** 用户向社交分类添加语录"别再刷了"，作者为"自己"
- **THEN** 新语录出现在集合中，后续的拦截页面中可能随机显示

#### Scenario: 编辑已有语录

- **WHEN** 用户修改语录的文本或作者
- **THEN** 更新后的语录被保存并在会话间持久化

#### Scenario: 删除语录

- **WHEN** 用户从分类中删除一条语录
- **THEN** 该语录被移除，不再出现在拦截页面上

#### Scenario: 重置语录为默认值

- **WHEN** 用户将某分类的语录重置为默认值
- **THEN** 所有用户修改被丢弃，仅保留内置默认语录
