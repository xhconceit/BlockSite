# BlockSite 需求文档

## 1. 产品概述

BlockSite 是一款浏览器网站拦截插件，帮助用户在工作和学习期间保持专注。用户可以自定义拦截规则，阻止访问分心的网站，并通过密码保护和定时拦截增强自律。

## 2. 目标用户

- 需要提高工作效率的上班族
- 需要专注学习的学生
- 希望控制上网习惯的普通用户

## 3. 功能需求

### 3.1 网站拦截

#### FR-01 多种拦截方式

| ID | 拦截类型 | 说明 | 示例 |
|----|---------|------|------|
| FR-01a | 域名拦截 | 匹配完整域名（忽略 www 前缀） | `facebook.com` 拦截所有 facebook 页面 |
| FR-01b | 路径拦截 | 匹配「域名 + 路径」前缀 | `youtube.com/shorts` 仅拦截 YouTube Shorts |
| FR-01c | 关键词拦截 | URL 中包含指定关键词即拦截 | `game` 拦截 URL 含 game 的所有页面 |
| FR-01d | 正则拦截 | 支持正则表达式匹配 | `.*\.torrent.*` 拦截种子文件网站 |

#### FR-02 拦截规则管理

- 添加规则：选择类型 → 输入值 → 选择分类 → 可选自定义提示
- 编辑规则：修改类型、值、分类、提示文字
- 删除规则：单条删除
- 启用/禁用：每条规则可单独开关
- 搜索：按拦截值搜索
- 筛选：按类型、分类筛选

#### FR-03 分类预设

系统内置以下分类预设规则，支持一键添加：

| 分类 | 预设网站 |
|------|---------|
| 社交媒体 | facebook.com, twitter.com, instagram.com, tiktok.com, weibo.com, douban.com, zhihu.com, tieba.baidu.com |
| 视频网站 | youtube.com, bilibili.com, netflix.com, iqiyi.com, youku.com, douyin.com, kuaishou.com |
| 游戏网站 | steampowered.com, epicgames.com, twitch.tv, nexusmods.com |
| 新闻资讯 | reddit.com, toutiao.com, 36kr.com, thepaper.cn |

### 3.2 分类拦截页面

#### FR-04 拦截页面展示

当用户访问被拦截的网站时，显示拦截页面，内容包括：

1. **拦截提示**：显示「网站已被拦截」及被拦截 URL
2. **分类主题**：根据拦截规则所属分类展示不同主题色
   - 社交 → 蓝色 `#3b82f6`
   - 视频 → 红色 `#ef4444`
   - 游戏 → 绿色 `#22c55e`
   - 新闻 → 橙色 `#f59e0b`
   - 成人 → 紫色 `#8b5cf6`
   - 自定义 → 靛色 `#6366f1`
3. **励志语录**：每个分类有 5 条默认语录，随机展示
4. **自定义提示**：规则可配置自定义文字，优先于默认语录显示

#### FR-05 临时解锁

- 用户可在拦截页面临时解锁 5 分钟
- 若启用了密码保护，需验证密码后才能解锁
- 解锁后显示倒计时，到期自动恢复拦截

### 3.3 全局控制

#### FR-06 全局开关

- Popup 弹窗中一键开启/关闭所有拦截
- 关闭后所有规则失效，已拦截网站可正常访问
- 开启后重新应用所有启用规则

#### FR-07 快速添加

- Popup 中显示当前网站域名
- 「拦截此站点」按钮一键将当前域名加入拦截列表

### 3.4 定时拦截

#### FR-08 时间段设置

- 设置拦截生效的时间段（如 9:00 - 18:00）
- 到达开始时间自动开启拦截
- 到达结束时间自动关闭拦截
- 支持按星期几选择生效日期

### 3.5 密码保护

#### FR-09 密码功能

- 设置密码后，修改设置和临时解锁需要验证
- 密码使用 SHA-256 哈希存储，不保存明文
- 支持移除密码保护

### 3.6 数据管理

#### FR-10 导入导出

- 导出配置为 JSON 文件（规则、定时、密码状态等）
- 从 JSON 文件导入配置，覆盖当前设置

#### FR-11 拦截统计

- 总拦截次数
- 今日拦截次数（每天零点重置）

## 4. 非功能需求

| ID | 需求 | 说明 |
|----|------|------|
| NFR-01 | 浏览器兼容 | Chrome/Edge (MV3)、Firefox (MV2)、Safari |
| NFR-02 | 性能 | 使用 declarativeNetRequest API，拦截在浏览器层面完成，无运行时开销 |
| NFR-03 | 离线可用 | 所有功能纯本地运行，不需要网络 |
| NFR-04 | 隐私 | 密码 SHA-256 哈希存储，数据完全本地化不上传 |
| NFR-05 | 体积 | 打包后 < 500KB |
| NFR-06 | 响应速度 | Popup 打开 < 500ms，设置页加载 < 1s |

## 5. 用户故事

- **US-01** 作为一名上班族，我希望在工作时间自动屏蔽社交媒体，避免分心
- **US-02** 作为一名学生，我希望拦截游戏网站，保持学习专注
- **US-03** 作为一名用户，我希望能临时解锁被拦截的网站（比如午休时看看）
- **US-04** 作为一名用户，我希望用密码保护设置，防止自己轻易绕过拦截
- **US-05** 作为一名用户，我希望看到拦截页面有励志语录，提醒我保持专注
- **US-06** 作为一名用户，我希望不同的拦截类型显示不同的提示，比如社交媒体提醒我「多和真实的人交流」
- **US-07** 作为一名用户，我希望能一键添加常见网站的拦截规则，不用逐个输入
- **US-08** 作为一名用户，我希望能导出配置备份，换电脑后快速恢复
